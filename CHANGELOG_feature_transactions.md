# Список изменений в ветке feature/transactions

## Обзор
Ветка: `feature/transactions`
Статус: Все изменения в рабочей директории (не закоммичены)

## Измененные файлы

### 1. app/transactions/models.py
**Изменения:**
- Добавлен enum `TransactionCategory` с полным списком категорий транзакций:
  - Продукты, Одежда и обувь, Дом и ремонт, Путешествия, Переводы
  - Косметика и бытовая химия, Спорт, Развлечения, Кафе и рестораны
  - Транспорт, Жилье, Образование, Работа, Еда, Досуг, Покупки
- Обновлено поле `category` в моделях `Transaction`, `CreateTransactionRequest`, `UpdateTransactionRequest` для использования `TransactionCategory` enum
- Исправлено поле `date` в `UpdateTransactionRequest` - теперь корректно принимает `Optional[date]` вместо `NoneType`
- Добавлен импорт `datetime.date` как `dt_date` для избежания конфликта имен

### 2. app/transactions/controllers.py
**Изменения:**
- Обновлен эндпоинт `get_transactions` для работы с `TransactionCategory` enum
- Добавлена обработка ошибок с детальными сообщениями в `get_transactions`
- Исправлено преобразование типов транзакций из БД (enum) в модели ответа
- Обновлен эндпоинт `create_transaction` для передачи `category.value` в репозиторий
- Обновлен эндпоинт `update_transaction` для работы с enum категориями
- Исправлено преобразование типов при возврате транзакций (enum из БД → enum модели)

### 3. app/repositories/transaction_repository.py
**Изменения:**
- Добавлена валидация членства пользователя в группе при создании транзакции
- Добавлена валидация членства пользователя в группе при обновлении транзакции
- Обновлен метод `get_all` для корректной обработки `transaction_type` (поддержка строк и enum)
- Улучшена обработка ошибок с более понятными сообщениями

### 4. app/core/dependencies.py
**Изменения:**
- Заменен `OAuth2PasswordBearer` на `HTTPBearer` для простой Bearer авторизации в Swagger UI
- Обновлена функция `get_current_user` для работы с `HTTPAuthorizationCredentials`
- Исправлена обработка токенов: `sub` теперь преобразуется из строки в int (т.к. jose требует строку)
- Добавлена детальная обработка ошибок с понятными сообщениями

### 5. app/core/security.py
**Изменения:**
- Исправлена функция `verify_password` для совместимости с `bcrypt 5.0.0`
- Добавлен fallback на прямой вызов `bcrypt.checkpw` при ошибках passlib
- Обновлена функция `create_access_token` и `create_refresh_token` для передачи `sub` как строки (требование jose)

### 6. app/auth/controllers.py
**Изменения:**
- Обновлен метод `login_user` для передачи `user.id` как строки в токены (`str(user.id)`)
- Обновлен метод `refresh_token` для передачи `user.id` как строки в токены
- Добавлена обработка ошибок с детальными сообщениями и логированием

### 7. app/db/models.py
**Изменения:**
- Обновлено использование enum типов для `Transaction.type` и `UserGroup.role`
- Использован `sqlalchemy.dialects.postgresql.ENUM` с `create_type=False` для корректной работы с существующими enum типами в PostgreSQL

### 8. main.py
**Изменения:**
- Добавлена настройка `swagger_ui_init_oauth` для улучшения работы Swagger UI

### 9. tests/pydantic/test_transactions_models.py
**Изменения:**
- Исправлен тест `test_transaction_list_response_types` - заменена категория на валидную из enum (`"Продукты"`)

### 10. scripts/seed_data.py (новый файл)
**Описание:**
- Скрипт для заполнения базы данных тестовыми данными
- Создает 4 пользователя с паролем `password123`
- Создает группы и транзакции для тестирования

4. **Ошибка валидации категорий** - добавлены все категории из БД в enum
5. **Проблемы с Swagger UI** - заменен OAuth2 на простой Bearer токен
